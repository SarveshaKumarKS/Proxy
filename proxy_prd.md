# Proxy

Tagline:

# Product Vision

Proxy is a real time multiplayer AI coordination platform where every user is represented by a persistent AI proxy agent.

Instead of humans manually negotiating group plans through chaotic group chats, AI representatives negotiate transparently on behalf of users using:
  • personal preferences
  • calendar constraints
  • personality styles
  • compromise history
  • travel fairness
  • live web data
  • social dynamics

Humans remain in control and can modify, veto, or relax constraints at any point.

The system continuously optimizes for:
  • fairness
  • coordination quality
  • reduced planning friction
  • emotionally intelligent consensus

# Core AI Architecture

# Agent Structure

Each user owns:
## one persistent proxy agent.

---

# Proxy Agent Responsibilities

Each proxy:
  • advocates for user preferences
  • evaluates tradeoffs
  • negotiates compromises
  • remembers historical patterns
  • communicates publicly

---

# Central Resolver Agent

Special orchestration layer.

Responsibilities:
  • summarize conflicts
  • compute fairness
  • detect bottlenecks
  • generate compromise proposals
  • synthesize final plans

---

# Negotiation Architecture

NOT autonomous recursive loops.

Use:
## controlled staged orchestration.

---

# Negotiation Cycle

## Step 1
Users submit preferences.

## Step 2
Parallel proxy generation.

## Step 3
Proxies independently propose:
  • venues
  • timing
  • formats
  • alternatives

## Step 4
Resolver detects conflicts.

## Step 5
Proxies negotiate compromise rounds.

## Step 6
Humans intervene if desired.

## Step 7
Final consensus proposal generated.
